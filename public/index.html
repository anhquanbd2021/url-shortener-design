Decision one

Mint the code — counter vs dice

A counter encoded in base62 is unique by construction: zero lookups on the write path. A random draw must be checked against the database on every insert — and retried on collision. Enable rig collisions to force the random generator to re-draw issued codes, so the failure is visible instead of lucky.

Decision two

The read path — one cache read

Redirect traffic is skewed: a handful of viral links carry almost all clicks. Fire 100 clicks with 90% aimed at one hot link and watch the cache absorb them. A miss costs a DB read; a hit costs ~1 ms.

Decision three

Analytics — after the redirect, never inside it

The popular diagram puts a click-row INSERT between the cache read and the 302. Then redirect latency is a database write. Queue the event instead: the user is already gone when it gets counted.

Decision four

301 vs 302 — the silent zero

301 Moved Permanently tells the browser to cache the redirect — possibly forever. The first click reaches your server; every later click resolves inside the browser. 302 must re-ask every time, so every click is counted. Send 10 repeat clicks each way and compare.
